# Shape Blur Contact Button Design

The About section contact action will keep its existing semantic email link while replacing the purple-orange gradient with the supplied Three.js ShapeBlur treatment.

The shader is isolated in a reusable client component and extends the React Bits scalar `shapeSize` behavior with a `shapeAspect` multiplier and an optional height-relative shape anchor. The visible outline is a horizontal rounded rectangle, while its transparent WebGL sensor canvas extends asymmetrically from the original top-left origin: 768 x 288 pixels on desktop and 480 x 224 pixels on mobile. The shape anchor keeps the outline at its existing position, so the established left and top response margins do not change while the sensor field grows to the right and downward. Pointer projection is deliberately separate from the shader's visual spread: real pointer positions inside the extended right or bottom sensor area are projected to a compact band just outside the nearest outline edge. This keeps distant right/down movement responsive without forcing the blur radius to cover the whole button. The renderer's measured device pixel ratio is written back to the mouse-coordinate uniform on every resize; this prevents pointer coordinates from being displaced on browsers or displays whose DPR differs from the component's preferred maximum. The doubled canvas height is balanced by smaller shape, roundness, border, circle, and edge uniforms, preserving the outline dimensions and returning the diffusion to a restrained local bloom. The semantic email link remains a separate layer whose hit area matches only the visible frame (about 233 x 74 pixels on desktop and 182 x 58 pixels on mobile). The outline is rendered exclusively by ShapeBlur: the link adds no CSS border, background, shadow, or decorative frame.

The visual direction is monochrome and editorial: translucent black surface, cool-white type, fine border, and restrained hover lift. This matches the black-and-white portrait and avoids introducing a competing accent color. The animation respects reduced-motion preferences, cleans up its WebGL resources, and does not change the surrounding ScrollExpand interaction.
